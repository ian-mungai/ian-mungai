## Projects

- **[Healthcare Realtime Monitoring](https://github.com/ian-mungai/healthcare-realtime-monitoring):** an AWS demonstration with fictional patient records and replayed public waveform-derived vital signs. One stream feeds realtime monitoring and a governed lakehouse with daily scoring. [Case study](https://www.ianmungai.com/projects/healthcare-realtime-monitoring)
- **[Healthcare Analytics Capstone](https://github.com/ian-mungai/healthcare-analytics-capstone):** a cloud pipeline that ingests public hospital quality data, curates it into prepared hospital datasets and supports regression analysis of a constructed infection index. [Case study](https://www.ianmungai.com/projects/healthcare-analytics-capstone)
- **[Maize Disease Classification](https://github.com/ian-mungai/maize-disease-classification):** an academic web application that classifies maize leaf images with a TensorFlow convolutional neural network. [Case study](https://www.ianmungai.com/projects/maize-disease-classification)
